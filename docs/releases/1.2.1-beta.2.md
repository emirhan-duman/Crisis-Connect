## Changes submitted for review

- Hardened SOS peer authorization and scoped contact identity binding.
- Authenticated authority mesh and push-to-talk traffic, including speaker identity and replay
  handling at the PTT protocol boundary.
- Per-pairing keys, independent Android database key migration, authenticated receipts and
  preservation of encrypted state during storage failures.
- Signal identity binding, explicit migration state, pairing consent and clearer re-pairing prompts.
- Rotating radio identifiers, stricter rescue certificate checks and bounded authority-key leases.
- Separate V2 SSO and authority-key endpoints with staged rollout controls.
- Fixed iOS CallKit activation timing and hardware-format selection for duplex GATT microphone
  capture; added opt-in device regression tests.

The source delta is based on the previous review snapshot, `v1.2.0-beta.1`
(`455e781beb80c48e8be0265f7ec83c71af289db9`). Confidential assessment documents and private
reproduction material are not included in this public release.

## Compatibility and rollout

- This release deploys no backend functions and enables no production rollout cohort.
- Legacy SSO/key-service contracts remain separate for installed clients. Their continued
  availability is a migration accommodation, not a claim that legacy clients gain V2 protections.
- V2 private offline pairing needs updated peers and a fresh QR. Existing conversation history is
  retained; quarantined legacy keys are not re-enabled for the new radio protocol.
- V2 authority keys use independent UTC-aligned 72-hour epochs, further limited by certificate
  expiry. A download near the end of an epoch has less than 72 hours remaining. An already issued
  key cannot be remotely erased from a disconnected device.
- V2 SSO/key-service acceptance requires a configured test backend and enrolled test accounts.
  Closed/default rollout cohorts intentionally deny V2 access.
- Existing watch, constrained-network and SFU features remain experimental and gated.

## Validation scope

The GitHub release records the checks completed against this frozen source snapshot.
The Android internal bundle/universal APK built successfully; 111 selected tests in 24 classes
passed with no failures, errors or skips. APK v2/v3 signature verification and 16 KB ZIP alignment
passed; the universal manifest includes both base and rescue modules.
Android lint passed with no new issues using the unchanged baseline. Existing baseline-filtered
findings remain technical debt; this release does not claim that all historical lint debt is fixed.
Web type checking and 35 focused SSO tests passed; the mirrored Functions TypeScript build and
two authority-key/rollout tests passed. iOS project metadata, package manifests and Swift syntax
passed the source validation script.

Earlier device validation used the active development apps on an S21 FE and an iPad Pro M5:
encrypted QR verification, a synthetic message with authenticated receipt, and duplex encrypted
voice traffic passed. The iOS BLE chat link in that test used a test central with production
framing/crypto and the production CallKit/audio coordinator. It was not a full UI/P2pGattChatManager
acceptance test, and audio quality was not assessed by a human listener.

Isolated SOS declaration/recovery/stop tests passed without public SOS advertising or real
recipient alerts. Full rescuer-radio, Wi-Fi Aware, multi-hop PTT, live identity-provider/SSO and
live key-revocation acceptance remain outside those results. No full iOS build of the public
source mirror is claimed: matching native static libraries remain local build prerequisites,
as documented for Beta 1.

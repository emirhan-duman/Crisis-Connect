# Crisis Connect 1.2.0

This GitHub release contains the public source for the 1.2.0 mobile update.

| Component | Version | Store build |
| --- | --- | --- |
| Android phone | 1.2.0 | 81 |
| Wear OS | 1.2.0 | 82 |
| iOS, Apple Watch and app extensions | 1.2.0 | 44 |

- Personnel check-ins appear in the mobile inbox. Participating organizations can configure response choices and accept notes or short voice replies. Offline replies are saved on the device and queued for sending when connectivity returns.
- Android supports full-screen check-in alerts where permitted. iOS supports Time Sensitive notifications according to device settings.
- QR contact pairing and Bluetooth and internet messaging handoffs are more responsive.
- Both watch companions show how to refresh status and reopen the phone app after a disconnect. Wear OS keeps the SOS control accessible on round displays.

The public source preserves the repository's opt-in telemetry safeguards. Local Firebase configuration, release signing files, and prebuilt iOS static libraries are supplied separately. See the [Android setup guide](../../Android/README.md) and the [iOS setup guide](../../iOS/README.md).

Hosted check-ins and standalone watch features require compatible deployed services. The source release retains the existing Firebase Functions tree.

GitHub provides source archives for this tag. Installable phone and watch builds are distributed through their respective app stores after review.
